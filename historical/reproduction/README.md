Their presence is not an approved execution route and does not repair the missing `Run_On_fir/activate_glue.sh` reference in other legacy wrappers. The eight metric YAMLs are historical evidence, not eight new thesis conditions and not regenerated results. See [source routes](../../provenance/integration_sources.json) for their exact original paths. The old README is retained as literal text to preserve its original checkout context.
