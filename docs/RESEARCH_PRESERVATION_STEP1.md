# SHARE gate-stability and gated-analysis preservation

This commit preserves existing reviewed experiment source and immutable design
files without editing active training, evaluation or submission code.

The SHARE experiment contains 192 GATED configurations: dimensions
16,32,50,64,100,128,200,256,384,512,768,1024,1536,2048,3072,4096;
gate initializations 0.25,0.50,0.75,0.95; model seeds 0,1,2; lam_keep=0.
The shared full dataset contains 32,231 cells per assay. The three run manifests,
91,300-edge non-self universe and existing preflight/hash configuration are
preserved byte-for-byte. The 3.3 MB edge CSV is an immutable gate-identity input,
not learned gates or a result table.

The commit also preserves the previously ignored PBMC gate-analysis report
generator and the PBMC tuning, initialization and dimension task designs.
Existing metrics, checkpoints, gate outputs, recovery archives, submission
records and logs are excluded. `preservation/source_manifest.tsv` records the
selected existing bytes and their original paths.

## Frozen execution dependencies

Pending Slurm wrappers execute `experiment.py run`, which verifies source and
input hashes. They do not rerun prepare. The historical manifests record base
commit ead6471; that remains the correct architecture provenance even after a
preservation commit is made. Do not rerun prepare/submit over this frozen design
merely to substitute a new Git commit: prepare constructs a commit-dependent
manifest and refuses a different existing manifest.

Source paths remain under `/project/6001426/paa40/GlUE_Exp/GLUE_GATED`.
Shared runners, dataset preparation and environment remain under the sibling
GLUE worktree. The validator patch is preserved as historical implementation
evidence; its changes are already present in the shared validator and must not
be blindly reapplied. Existing batch B's four-hour default differs from some
recorded live resource overrides; no resource or job setting was changed here.

No scientific result is newly generated by this commit. No active file is
renamed, rewritten or moved, and no job is submitted, cancelled or rescheduled.
