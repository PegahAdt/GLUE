# Ma-2020 SHARE-seq architecture and gate-sensitivity experiment

This workspace is isolated from all PBMC outputs.  The authoritative inventory is
`manifests/master_experiment_manifest.csv`.  Run `./submit_all.sh` to prepare and
submit the dependency-chained workflow, and `./status.sh` to inspect it.

Validated model implementations are imported from the existing checkouts:

- GCN: `/project/6001426/paa40/GlUE_Exp/GLUE`
- GAT: `/project/6001426/paa40/GlUE_Exp/GLUE_GAT`
- GATED: `/project/6001426/paa40/GlUE_Exp/GLUE_GATED`

No model architecture file is copied or modified here. Pairing is preserved in
the prepared inputs and manifests but is never passed to GLUE training. It is
used only by paired evaluation metrics.


Unimodal metric inputs are generated by the canonical RNA PCA and ATAC LSI
scripts (50 dimensions) and cached in `data/unirep_cache/<sha256>/` as
`rna_unirep.h5ad` and `atac_unirep.h5ad`. The key includes ordered cell IDs,
prepared source provenance, script hashes, and dimension; it excludes model
seed, architecture, and gate initialization. A filesystem lock prevents
concurrent metrics jobs from duplicating PCA/LSI. Files are validated before
atomic publication. There are 11 pairs: smoke, nine subsamples, and full data.
Pairs are generated on first evaluation and reused thereafter. Each result's
`unirep_inputs.json` records its cache paths. Dataset, representation, manifest,
and latent observation orders must match exactly before paired metrics run.

To rescue completed smoke training, submit `slurm/rescue_smoke.sbatch`.
It validates the final model and all latent outputs, evaluates with cached
unireps, and extracts/validates gates before writing `SMOKE_OK`. It does not
train. `submit_all.sh` requires that validation job to have COMPLETED before
submitting the expensive matrix. A saved smoke final model also directs the
ordinary smoke script into validation rather than retraining.
