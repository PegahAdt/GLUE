# PBMC latent dimension comparison

[Thesis map](../../../THESIS_EXPERIMENTS.md) · `REPRODUCIBILITY.md` (external, planned, or unresolved)

## Scientific objective

How does embedding dimension affect each architecture at 2000 and 8000 paired cells?

## Dataset, architectures and conditions

PBMC 10x Multiome: paired human PBMC scRNA-seq + scATAC-seq.

GCN mode of GAT branch for fresh GCN dimension jobs, raw GAT, and GATED; historical 50D sources are reused separately..

Three architectures × dimensions 16/32/50/64/100 × 2,000/8,000 paired cells; subset/model seeds 0/0. Current manifest: 24 unchanged non-50D configurations + six saved 50D references = 30.

The canonical registry has **30 rows**. Reused rows and overlapping analysis views are not new independent fits.
